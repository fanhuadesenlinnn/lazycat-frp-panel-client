运行选项

粘贴上游启动命令

直接把 frp-panel 主控 WebUI 里复制的启动命令粘进来。管理器在进程内解析，不会交给 shell 执行。

解析结果

    解析规则与安全说明
    • 只识别 -s/-i/--api-url/--rpc-url；旧参数 --api-host/--rpc-host/--api-port/--rpc-port/--api-scheme 会被推导为 URL 并给出提示。
    • 含管道、重定向、命令替换（|、>、$( 等）的文本会被直接拒绝，避免被当作 shell 命令。
    • 命令中的程序路径仅用于展示，实际始终执行镜像内自带的、随包固定版本的上游客户端。
    • 第一版不支持 --join-token 自动加入，请在 Master 上创建客户端后复制含密钥的命令。
    • 命令里若带有 CLIENT_FEATURES_ENABLE_* / LOGGER_* 环境变量赋值，会被忽略并给出提示：功能开关请在下方勾选框里显式设置，日志级别请用下拉框。

    客户端日志

    有界内存缓冲（— 行），密钥已统一脱敏，容器重启后清空。
